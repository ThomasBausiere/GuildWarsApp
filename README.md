# 🛡️ GuildWarsApp – Outil communautaire pour joueurs de Guild Wars

## 🇫🇷 Présentation

**GuildWarsApp** est une application front-end développée avec **Angular**, pensée comme un outil d'accompagnement pour les joueurs du jeu **Guild Wars** (2005), développé par ArenaNet et édité par NCSoft. Ce projet personnel est réalisé en parallèle de ma formation, dans une démarche d'exploration technique et de passion pour le jeu.

L'application est en cours de développement et a pour objectif de centraliser des **ressources utiles**, des **outils communautaires** et une **interface d’aide à la complétion** du jeu, à destination des joueurs.

---

## 🧭 Structure de l'application

- **🏠 Accueil**  
  Propose des liens rapides vers des ressources en ligne (wikis, bases de données…) permettant un accès direct aux outils utilisés régulièrement par la communauté.

- **🎮 Game**  
  Sera, à terme, une base de données complète regroupant toutes les informations clés sur le jeu. Cette section est destinée à devenir une sorte de "wiki personnel", organisé et synthétique.

- **💱 Trade**  
  Interface d’échange communautaire :
  - Redirections vers les sites de trading en ligne.
  - Intégration d’une iframe du site [kamadan.gwtoolbox.com](https://kamadan.gwtoolbox.com), affichant en temps réel les messages du marché du jeu.
  - Bloc-notes intégré pour permettre aux utilisateurs de prendre des notes personnalisées (via localStorage).

- **📜 Chasseur de compétences** (en construction)  
  Cette future section permettra aux joueurs de suivre leur progression dans la **capture des compétences élites**. Elle sera connectée à une **API développée en Java**, qui regroupera plus de 300 compétences et leurs boss associés. Les utilisateurs pourront cocher/décocher celles qu’ils possèdent pour visualiser leur progression.

---

## 🧰 Stack technique

- **Framework** : Angular  
- **Langages** : TypeScript, HTML, CSS  
- **Fonctionnalités locales** : localStorage  
- **API à venir** : Backend Java (en développement)

## 🇬🇧 Overview

**GuildWarsApp** is a front-end web application built with **Angular**, designed as a companion tool for players of **Guild Wars** (2005), developed by ArenaNet and published by NCSoft. This is a personal project developed alongside my training, combining technical experimentation with my passion for the game.

The app is currently under development and aims to centralize **useful resources**, **community tools**, and a **completion tracker** for the game's more dedicated players.

---

## 🧭 App Structure

- **🏠 Home**  
  Quick links to various external tools and resources commonly used by the Guild Wars community.

- **🎮 Game**  
  Will eventually serve as a full knowledge base of the game, providing a clean and structured wiki-like resource.

- **💱 Trade**  
  Community trading hub:
  - Redirection to external trading websites
  - Embedded iframe from [kamadan.gwtoolbox.com](https://kamadan.gwtoolbox.com) for real-time market messages
  - Integrated notepad for personal notes (stored via localStorage)

- **📜 Skill Hunter** (under construction)  
  This upcoming section will help players track their progress in collecting **elite skills** by interfacing with a **Java backend API**. With over 300 elite skills and bosses, users will be able to tick off which ones they’ve obtained and identify what’s still missing.

---

## 🧰 Tech Stack

- **Framework**: Angular  
- **Languages**: TypeScript, HTML, CSS  
- **Local features**: localStorage  
- **Upcoming API**: Java backend (in progress)
